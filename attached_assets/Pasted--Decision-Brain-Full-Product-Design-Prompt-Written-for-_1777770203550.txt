# Decision Brain — Full Product Design Prompt
### Written for a Senior Full-Stack Developer / Technical Architect

---

## 1. PRODUCT OVERVIEW

**Product Name:** Decision Brain  
**Type:** AI-powered Personal Decision Intelligence OS  
**Target Users:** CEOs, Founders, Board Members, VCs, C-Suite Executives  
**Core Value Proposition:** Silently captures every decision a leader makes across all platforms, detects patterns, tracks outcomes, and warns about blind spots — so leaders make smarter, faster decisions using their own history as intelligence.

## 2. TECH STACK

### Frontend
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS + shadcn/ui component library
- **State Management:** Zustand (global) + React Query (server state)
- **Charts & Visualization:** Recharts + D3.js for custom graphs
- **Animations:** Framer Motion
- **Real-time UI:** Socket.io client (live capture feed)
- **Auth UI:** Clerk (supports SSO, Google OAuth, enterprise SAML)

### Backend
- **Runtime:** Node.js 20 + Express.js (REST) + tRPC (type-safe internal APIs)
- **Language:** TypeScript
- **Queue System:** BullMQ + Redis (for async platform capture jobs)
- **WebSocket Server:** Socket.io (live decision feed)
- **Cron Jobs:** node-cron (outcome check scheduler, weekly reports)
- **File Storage:** AWS S3 (meeting recordings, document uploads)

### AI / ML Layer
- **Primary LLM:** Google Gemini 1.5 Pro (decision extraction, pattern matching, board reports)
- **Fast/Realtime LLM:** Google Gemini 1.5 Flash (live call overlay, quick classification — cheaper + faster)
- **Long Context LLM:** Google Gemini 1.5 Pro (2M token context — full year of transcripts in one call)
- **Embeddings:** Google text-embedding-004 via Vertex AI (768-dim, semantic similarity search)
- **Vector Database:** Pinecone (stores decision embeddings for similarity matching)
- **Speech-to-Text:** Google Cloud Speech-to-Text v2 (real-time call transcription — native Google ecosystem)
- **Fallback LLM:** Anthropic Claude 3.5 Sonnet (backup if Gemini is unavailable)
- **Orchestration:** LangChain.js with @langchain/google-genai adapter (multi-step AI pipelines)
- **AI SDK:** @google/generative-ai (Node.js) + @google-cloud/vertexai (enterprise/prod)

### Database
- **Primary DB:** PostgreSQL 15 via Supabase
  - Users, decisions, outcomes, alerts, integrations
- **Cache:** Redis (session data, live feed buffer, rate limiting)
- **Vector Store:** Pinecone (decision embeddings, semantic search)
- **Search:** Elasticsearch (full-text search over decision history)

### Integrations & Platform Connectors
- **OAuth Manager:** Custom connector service per platform
- **Queue:** BullMQ workers per integration (Gmail, Slack, Zoom, etc.)
- **Webhook Receiver:** Express routes per platform
- **Rate Limit Handler:** Per-platform rate limit config with exponential backoff

### Infrastructure
- **Cloud:** Google Cloud Platform (AI/ML, Speech, Storage) + AWS (primary infra) + Vercel (frontend)
- **Container:** Docker + Docker Compose (local dev) + GKE or ECS Fargate (prod)
- **CI/CD:** GitHub Actions → Artifact Registry (GCP) → Cloud Run or ECS
- **Secrets:** Google Secret Manager (for GCP services) + AWS Secrets Manager (for AWS services)
- **Monitoring:** Datadog (APM + logs) + Sentry (error tracking)
- **CDN:** Cloudflare
- **DNS:** Cloudflare DNS

## 3. DATABASE SCHEMA

```sql
-- Core user
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  avatar_url TEXT,
  plan TEXT DEFAULT 'pro', -- pro | enterprise
  timezone TEXT DEFAULT 'UTC',
  preferences JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Every captured decision
CREATE TABLE decisions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  description TEXT,
  source_platform TEXT, -- 'gmail' | 'zoom' | 'slack' | 'meet' | 'manual'
  source_ref TEXT,       -- original message ID / meeting ID
  raw_context TEXT,      -- full original text that triggered detection
  stakes TEXT DEFAULT 'medium', -- 'low' | 'medium' | 'high' | 'critical'
  status TEXT DEFAULT 'active', -- 'active' | 'reversed' | 'pending'
  tags TEXT[],
  metadata JSONB DEFAULT '{}',
  embedding VECTOR(768),         -- Gemini text-embedding-004 (768 dimensions)
  decided_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Outcome tracking per decision
CREATE TABLE outcomes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  decision_id UUID REFERENCES decisions(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  score INTEGER CHECK (score >= 0 AND score <= 100),
  notes TEXT,
  tracked_at TIMESTAMPTZ DEFAULT NOW(),
  check_interval TEXT DEFAULT '90d' -- '30d' | '90d' | '180d' | '1y'
);

-- AI-generated pattern alerts
CREATE TABLE alerts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  decision_id UUID REFERENCES decisions(id),
  alert_type TEXT, -- 'pattern_match' | 'blind_spot' | 'repeat_mistake' | 'similarity'
  title TEXT,
  description TEXT,
  severity TEXT DEFAULT 'medium', -- 'low' | 'medium' | 'high'
  similar_decision_ids UUID[],
  is_read BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Platform integration credentials + status
CREATE TABLE integrations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  platform TEXT NOT NULL, -- 'gmail' | 'zoom' | 'slack' | 'meet' | etc.
  status TEXT DEFAULT 'disconnected', -- 'connected' | 'disconnected' | 'error'
  access_token TEXT,       -- encrypted at rest
  refresh_token TEXT,      -- encrypted at rest
  token_expiry TIMESTAMPTZ,
  scope TEXT[],
  metadata JSONB DEFAULT '{}',
  last_synced_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, platform)
);

-- Board briefing reports
CREATE TABLE reports (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  title TEXT,
  report_type TEXT DEFAULT 'board_briefing', -- 'board_briefing' | 'weekly' | 'pattern_analysis'
  content TEXT,  -- markdown
  decision_ids UUID[],
  period_start DATE,
  period_end DATE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 4. FULL FEATURE LIST

### 4.1 Passive Decision Capture Engine
- Background workers poll connected platforms every 5 minutes
- NLP pipeline extracts decision signals from raw text
- Confidence scoring (0–100) determines if content is a real decision
- Only decisions with confidence > 70 are auto-logged; 50–70 go to "Needs Review"
- Deduplication layer prevents double-logging same decision from multiple sources
- Speaker identification in meeting transcripts (who made the decision)

### 4.2 Decision Log
- Full searchable history of all logged decisions
- Filter by: platform, stakes level, date range, tags, outcome score
- Manual add / edit / delete decisions
- Bulk tagging and categorization
- Attach files, notes, context documents
- Decision timeline view (chronological visual)
- Export to CSV / PDF

### 4.3 AI Pattern Engine
- On every new decision logged, run embedding similarity search in Pinecone
- Compare against past decisions using cosine similarity (threshold: 0.82)
- If match found → generate alert with explanation and outcome history
- Pattern categories: repeat mistake, successful pattern, blind spot trigger, escalation pattern
- Weekly pattern digest email

### 4.4 Blind Spot Detector
- Analyze decision clusters over time for missing data sources
- Flag decisions where:
  - No external data was referenced
  - Same category decision failed >2x before
  - Time pressure was mentioned (urgency bias)
  - Decisions made against prior advice
- Visual blind spot map per category (M&A, hiring, pricing, etc.)

### 4.5 Outcome Tracker
- Auto-schedule outcome check-ins at 30 / 90 / 180 days per decision
- Reminder notifications via email + in-app
- Score each outcome 0–100 with notes
- Outcome score feeds back into AI training per user profile
- Aggregate stats: win rate, avg score per category, trend over time

### 4.6 Board Report Generator
- Select decisions → one-click AI generates board briefing doc
- Sections: Summary, Context, Alternatives Considered, Outcome Status, Learnings
- Export as PDF / DOCX / Google Slides
- Custom branding (logo, colors) for enterprise plan

### 4.7 Decision Intelligence Chat
- Chat interface over entire decision history
- Natural language queries: "When did I last make an M&A decision?" / "Show me all decisions where I overrode the AI alert"
- Powered by RAG (Retrieval Augmented Generation) over decision embeddings
- Streaming responses (SSE)

### 4.8 Live Call Overlay (Browser Extension)
- Chrome extension detects active Google Meet / Zoom tab
- Floating widget appears during call
- Real-time transcript shown with decision moments highlighted
- One-click to confirm a flagged decision
- Post-call summary with all decisions extracted

### 4.9 Weekly Intelligence Digest
- Auto-generated every Monday morning
- Sections: decisions made, patterns detected, outcomes due, blind spots, suggested focus
- Delivered via email (HTML) + in-app notification
- Full digest viewable in app with drill-down links

## 6. AI PIPELINE ARCHITECTURE

```
Platform Event Received (email / transcript / message)
        ↓
[1] Text Extraction Worker (BullMQ job)
        ↓
[2] Decision Detection Prompt (Gemini 1.5 Flash — fast + cheap)
    Input:  raw text + user context
    Output: { isDecision: bool, confidence: int, title, description, stakes, tags }
        ↓
[3] Confidence Gate
    < 50  → discard
    50–70 → queue for manual review
    > 70  → auto-log
        ↓
[4] Embedding Generation (Google text-embedding-004 → 768-dim vector)
        ↓
[5] Pinecone Upsert (store embedding with metadata)
        ↓
[6] Similarity Search (cosine, top-5 matches above 0.82)
        ↓
[7] Pattern Alert Generator (Gemini 1.5 Pro — deep reasoning)
    Input:  new decision + similar past decisions + outcome scores
    Output: alert title, description, severity, type
        ↓
[8] Alert stored in DB + pushed to user via WebSocket
```

### Gemini Model Usage by Task

| Task | Model | Why |
|---|---|---|
| Decision detection (realtime) | Gemini 1.5 Flash | Low latency, high throughput, cheap |
| Full meeting transcript analysis | Gemini 1.5 Pro | 2M token context, handles 10hr recordings |
| Pattern alert generation | Gemini 1.5 Pro | Deep multi-step reasoning |
| Board report writing | Gemini 1.5 Pro | Long-form structured output |
| RAG chat (decision history) | Gemini 1.5 Pro | Large context for full history |
| Embeddings | text-embedding-004 | Best Google embedding, 768-dim |
| Speech-to-text (calls) | Google STT v2 | Native Google ecosystem, streaming |
| Fallback (all tasks) | Claude 3.5 Sonnet | If Gemini quota exceeded |

### Gemini Code Example — Decision Detection

```typescript
import { GoogleGenerativeAI } from '@google/generative-ai'

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!)

export async function detectDecision(rawText: string, userContext: string) {
  const model = genAI.getGenerativeModel({
    model: 'gemini-1.5-flash',
    generationConfig: {
      responseMimeType: 'application/json',
      temperature: 0.1,
    }
  })

  const prompt = `
    You are a decision intelligence system for senior executives.
    Analyze the following text and determine if it contains a business decision.

    User context: ${userContext}
    Text: ${rawText}

    Respond ONLY with valid JSON:
    {
      "isDecision": boolean,
      "confidence": number (0-100),
      "title": string (short decision title, or null),
      "description": string (full decision context, or null),
      "stakes": "low" | "medium" | "high" | "critical",
      "tags": string[],
      "decidedBy": string (person who made decision, or null)
    }
  `

  const result = await model.generateContent(prompt)
  const text = result.response.text()
  return JSON.parse(text)
}
```

### Gemini Code Example — Embedding Generation

```typescript
import { GoogleGenerativeAI } from '@google/generative-ai'

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!)

export async function generateEmbedding(text: string): Promise<number[]> {
  const model = genAI.getGenerativeModel({ model: 'text-embedding-004' })
  const result = await model.embedContent(text)
  return result.embedding.values  // 768-dimensional vector
}
```

### Gemini Code Example — Long Meeting Transcript (2M context)

```typescript
export async function analyzeFullMeetingTranscript(transcript: string) {
  const model = genAI.getGenerativeModel({
    model: 'gemini-1.5-pro',  // 2M token context window
    generationConfig: { temperature: 0.2 }
  })

  const prompt = `
    Analyze this full meeting transcript and extract ALL decisions made.
    For each decision provide: title, context, who decided, stakes level, tags.
    Transcript: ${transcript}
    Respond in JSON array format.
  `

  const result = await model.generateContent(prompt)
  return JSON.parse(result.response.text())
}
```

## 8. SECURITY & PRIVACY ARCHITECTURE

- All OAuth tokens encrypted at rest using AES-256 (AWS KMS)
- All decision content encrypted at rest in PostgreSQL (column-level encryption)
- Zero-knowledge design: AI model never sees raw PII — PII stripped before embedding
- Per-user data isolation (Row Level Security in PostgreSQL via Supabase)
- Audit log for every data access event
- SOC 2 Type II compliance target
- GDPR-compliant data deletion (cascade delete all user data)
- Option for self-hosted deployment (enterprise plan)
- End-to-end encryption option for highest tier (keys stored only on device)
